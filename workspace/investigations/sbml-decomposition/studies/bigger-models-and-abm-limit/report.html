Bigger models and the ABM limit (adversarial)

Where do the SBML/Tellurium assumptions stop holding: (a) as an SBML model grows to hundreds-to-thousands of species, where does a monolithic libroadrunner/CVODE instance strain, and does decomposing it come out ahead end-to-end; (b) can an agent-based model even BE an SBML/Tellurium model, and where does its mean-field ODE reduction hold and structurally break?

Claim. The one strong, well-measured result is that the MONOLITHIC libroadrunner BUILD strains superlinearly in the reaction count: 0.20 s at 97 species -> 1.76 s at 385 -> 5.54 s at 769 -> 18.5 s at 1537 species (~94x for ~16x the reactions, ~O(N^1.64)), with the dense-CVODE run blowing up alongside it (0.0023 s -> 2.56 s). That is the real strain point and the reason a very large SBML model is painful to run monolithically. Decomposition is NOT a free win: building N small models is SLOWER than the single compile up to ~100 species (1.7x slower at 97 species), reaches only rough parity at 385 species (1.40 vs 1.76 s) and becomes a clear build win only at ~1500 species (2.4x); and the decomposed per-tick RUN overhead is ~16x the monolith's CVODE run, so the decomposed body is SLOWER END-TO-END at every N measured (decomp_total 2.35 s vs mono_total 1.81 s at 385 species). The end-to-end gap narrows with N but the decomposed run is unmeasured past N=128, so no end-to-end crossover is claimed. Decomposition is a structural trade — it swaps the monolith's superlinear build for much higher run overhead — that would only pay off end-to-end on models larger than measured. CRUCIAL caveat: the additive-split accuracy is good only at small N / fine interval (max_rel_err 2e-3 at N=2, 1.2e-2 at N=8, 5.2e-2 at N=32) and is 0.31 (31%) at N=128 — so the regime where the speed gap narrows and the regime of acceptable accuracy do NOT co-occur at a fixed coupling interval. All numbers measured, not fabricated. ALSO: An agent-based model reduces to an SBML/Tellurium mean-field ODE ONLY in the large-population, well-mixed, deterministic limit; it structurally cannot capture stochasticity, discreteness, extinction, or individual heterogeneity. MEASURED (Lotka-Volterra, base rates r=a=b=m=1, start density (1.8, 1.0), horizon ~2 periods, seed 0): at a LARGE population scale K=400 (80 SSA runs) the mean-field ODE reproduces the SSA ensemble mean to a max relative error of 4.9% with 0% of runs seeing predator or total extinction — the reduction is VALID. At a SMALL scale K=8 (200 SSA runs) the stochastic system collapses: the PREDATORS go extinct in 86.5% of runs and BOTH species in 51.0%, hitting absorbing states that the neutrally-stable ODE — which simply orbits forever, 0% extinction of either species at any K — can never reach, and the ensemble mean diverges several-fold from the ODE (predator-extinct runs let the prey escape, so the mean no longer resembles the bounded ODE cycle). The ODE additionally cannot represent the ensemble variance at ANY K. So "can an ABM be an SBML model?" has an honest, quantified answer: yes, but only as its large-population mean-field limit, and that reduction silently discards exactly the stochastic/discrete phenomena (extinction, demographic noise) that are often the biological point. This breaks the naive "just write it as SBML" claim.

Findings

  • [scale] STRONG RESULT — the monolithic libroadrunner BUILD (compile) strains superlinearly: measured medians 0.20 s at 97 species, 1.76 s at 385, 5.54 s at 769, 18.5 s at 1537 species — ~94x the build cost for ~16x the reactions (~O(N^1.64)). The dense-CVODE integration blows up alongside it (0.0023 s -> 0.058 s -> 0.395 s -> 2.56 s). Both halves of the monolithic cost grow superlinearly; this is the real, well-measured strain point and this study's headline.
  • [scale] HONEST NEGATIVE — decomposition does NOT build "several-fold faster by hundreds of species". The decomposed build is N separate libroadrunner setups: SLOWER than the single monolithic compile up to ~100 species (97 sp: 0.34 s vs 0.20 s, 1.7x slower), roughly at PARITY by 385 species (1.40 vs 1.76 s), and a clear win only at ~1500 species (7.75 vs 18.5 s, 2.4x). The build crossover is at the hundreds-of-species scale, not before.
  • [scale] HONEST NEGATIVE (end-to-end) — the decomposed per-tick RUN overhead dwarfs the monolith's raw CVODE run: at 385 species decomp_run 0.95 s vs mono_run 0.058 s (~16x). So the decomposed body is SLOWER END-TO-END at every N measured: mono_total vs decomp_total = 0.017 vs 0.044 s (N=2), 0.039 vs 0.143 (N=8), 0.200 vs 0.559 (N=32), 1.81 vs 2.35 (N=128). The end-to-end gap narrows as N grows (3.6x -> 1.3x), but the decomposed run is UNMEASURED past N=128 (too slow for the harness), so NO end-to-end crossover is claimed. Decomposition trades the monolith's superlinear build for higher run overhead; it would only pay off end-to-end on models larger than we measured.
  • [scale] The coupling is genuine: Glc_blood lives in ONE shared store and every organ writes the delta it produced on it, reconciled additively through the bigraph apply path (biological-modular-seam pattern). The shared pool drains more as more organs are added (monotone in N — a test asserts 8 organs drain it below the 2-organ case), which is only possible if the organs genuinely share the pool (contrast ensemble-and-multirate's N INDEPENDENT monoliths).
  • [scale] CRUCIAL caveat — accuracy and speed do NOT line up. The decomposed-vs-monolithic max_rel_err is a first-order additive-split error: 2e-3 at N=2, 1.2e-2 at N=8, 5.2e-2 at N=32, 0.31 (31%) at N=128. It HALVES as the coupling interval halves (verified) and GROWS with coupling density (more organs competing for the one pool per interval). The N=128 point where the end-to-end gap is smallest is exactly where accuracy (0.31) is unusable — so the speed crossover regime and the acceptable-accuracy regime do not co-occur at a fixed interval. Restoring accuracy at large N needs a finer interval, which adds more ticks and makes the decomposed run even slower. This is why the study verdict is PARTIAL.
  • [ABM limit] REDUCTION VALID AT LARGE N — at population scale K=400 (80 Gillespie-SSA runs, ~2 Lotka-Volterra periods, seed 0) the mean-field ODE integrated by libroadrunner/CVODE reproduces the SSA ensemble mean to a max relative error of 4.9% (mean 1.0%), with 0% predator extinction and 0% total extinction (robust across seeds: max rel err 0.033-0.056, extinction always 0). This is the Kurtz large-population limit in action: at enough individuals the discrete stochastic model and its continuous deterministic SBML reduction agree, so the ABM genuinely DOES reduce to an SBML model here.
  • [ABM limit] REDUCTION INVALID AT SMALL N — at scale K=8 (200 SSA runs, seed 0) the stochastic system COLLAPSES: the PREDATORS go extinct in 86.5% of runs and BOTH species in 51.0% (prey extinction, which is absorbing, then starves the predators), while the mean-field ODE — neutrally stable closed orbits — simply cycles forever and NEVER goes extinct (0% of either species, at any K). The ensemble mean diverges several-fold from the ODE (predator-extinct runs let the prey escape, so the mean bears no resemblance to the bounded ODE cycle). Robust across seeds (predator extinction 0.845-0.865, total 0.485-0.530). The deterministic SBML reduction misses the single most important qualitative behaviour of the small-population system — that the predators crash and the system can die out.
  • [ABM limit] HONEST EXTINCTION ACCOUNTING — only PREY extinction is truly absorbing; when the predators die but prey survive, the prey keep reproducing (pure birth r*X), so the SSA is NOT frozen on predator extinction (an earlier freeze inflated the single "extinction" number to 0.94 — the corrected, split numbers are 86.5% predator / 51.0% total). Prey that escape after their predators are gone are bounded by a documented population cap (25*K) that halts the unbounded runaway; the cap sits far above the deterministic orbit peak (~1.8 in density) so it never triggers while both species coexist. The headline metric is predator_extinct_fraction (the LV collapse the ODE can never show); total_extinct_fraction is reported alongside.
  • [ABM limit] STRUCTURAL LIMIT, NOT A TOLERANCE — the gap is not something a finer integrator or looser tolerance closes. The ODE state is (prey, predator) concentrations; it has no representation of integer discreteness, of demographic noise variance, or of the extinction probability, at ANY K. Those are properties of the ensemble and the absorbing boundary, which a single deterministic trajectory cannot carry. The ABM was NOT tuned to match the ODE — the large-N agreement and the small-N collapse are both measured.
  • [ABM limit] FEASIBILITY STATEMENT — "can an ABM even be an SBML/Tellurium model?" Answer: yes, but ONLY as its large-population, well-mixed, deterministic mean-field limit. That reduction is a real, runnable SBML model (the predator_prey_meanfield composite's Antimony) and is faithful when individuals are many; it silently discards stochasticity, discreteness, extinction and individual heterogeneity, which at small population size ARE the behaviour. This is the adversarial result that breaks the naive "just decompose/rewrite any model as SBML" claim the rest of the investigation operates under.

Model — the mean-field SBML reduction (Lotka-Volterra, Antimony)

This is the mean-field ODE reduction (the predator_prey_meanfield composite), integrated by libroadrunner/CVODE — a real, runnable SBML model. The agent-based model itself (predator_prey_abm, a Gillespie-SSA process over integer populations) is NOT an SBML model: it has no continuous RHS, and its stochasticity / discreteness / extinction cannot be written as ODE state. That gap is the finding.

Show the mean-field Lotka-Volterra Antimony
model lotka_volterra_meanfield
  # Mean-field (large-population, deterministic) limit of the stochastic ABM.
  # Species are continuous population counts; K = 400 is the system size.
  Prey = 720;
  Pred = 400;
  r = 1.0;   # prey birth (per capita)
  a = 1.0;   # predation
  b = 1.0;   # predator birth from predation
  m = 1.0;   # predator death (per capita)
  K = 400;

  prey_birth:     => Prey; r*Prey;
  predation:      Prey => ; (a/K)*Prey*Pred;
  predator_birth: => Pred; (b/K)*Prey*Pred;
  predator_death: Pred => ; m*Pred;
end
